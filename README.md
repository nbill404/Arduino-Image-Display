# Arduino-Image-Display
Arduino project that reads from a SD card and outputs images onto a 128x128 OLED display
SD card is loaded with text files containing hex strings in RGB565 format separated by commas

Components
- Arduino UNO R4 Wifi
- [OLED Screen](https://www.jaycar.com.au/duinotech-arduino-compatible-1-5-inch-colour-oled-display/p/XC3726)
- [SD Card](https://www.jaycar.com.au/arduino-compatible-sd-card-interface-module/p/XC4386)
